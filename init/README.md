# init/ —— 被测模型的起始空工程

本目录即 R0 下发给被测模型时的初始工作区，**故意保持为空**（除本说明外）。

用途与约束：

- 评测开始时把本目录整体复制到模型的沙箱工作区，模型从零开始搭建工程。
- 这里**不放**任何参考实现、schema、路由、状态机定义，避免泄题。
- 唯一的下发内容是 `instruction.md` §7 中 R0–R9 的 Prompt 原文（按轮次逐条发出），
  以及 §6「统一接口契约」中允许公开的部分（默认不发，详见 §6 的说明）。

判分侧的可运行基线在 `../golden_answer/`；测试适配点在 `../test/README.md`。
