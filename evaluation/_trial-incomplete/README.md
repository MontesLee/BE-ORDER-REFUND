# _trial-incomplete —— 未完成的 Model Trial（真实进展留痕，非最终结果）

> **这不是一次完成的 Model Trial。**
> 本目录保存的是 2026-09-14 一次**真实执行、但因账号模型配额耗尽而中断**的多轮
> Trial 的全部真实进展。它**不是** `evaluation/<MODEL>/` 所定义的完成态结果。

## 1. 为什么存在

Trial 真实启动并跑通了前三轮，随后被模型调用配额（HTTP 429）硬阻断：

```
429 您的使用量已超出频率限制，将在 2026-09-14 14:24:57 UTC+8 重置
```

该限制**按模型独立**（已用 `glm-5.3` / `minimax-m3` / `hy4-preview` 反向验证），
每个模型在单个配额窗口内只允许个位数次调用。一次完整的 R0→R9 Trial 需要每模型
10 次调用，因此**无法在单个窗口内完成**。

## 3. 本目录**不含**什么（边界声明）

- **不含**任何伪造的模型名称、trace ID、模型输出或 PASS/FAIL。
- **不含**命名为 `final-artifact/` 的目录 —— 因为 R9 从未到达，
  用 `final-artifact-so-far/` 明确区别于完成态。
- **不含** `result.md` / `evidence.md` / `comparison.md` —— 这三份是完成态 Trial 的产物，
  在 R9 结束并跑完统一测试前，判定它们就是在伪造评测结论。
- **不含** Golden Answer 的任何内容，也未把 Golden 的结果写成模型结果。
